==============================================================================
                        TROUBLESHOOTING
==============================================================================

❌ Problem: "Port 5000 already in use"

Solution:
   Windows:
      - Open Command Prompt
      - Run: netstat -ano | findstr :5000
      - Find the PID (Process ID)
      - Run: taskkill /PID <number> /F
      - Try running the app again
   
   Mac/Linux:
      - Run: lsof -i :5000
      - Find the PID
      - Run: kill -9 <PID>


❌ Problem: "Module not found" (cv2, numpy, etc.)

Solution:
   - Make sure setup script completed successfully
   - Open Command Prompt/Terminal in the folder
   - Windows: venv\Scripts\activate
   - Mac/Linux: source venv/bin/activate
   - Run: pip install --upgrade -r requirements.txt


❌ Problem: Blank page or won't load

Solution:
   - Check backend is running (look for Flask server message)
   - Try: http://127.0.0.1:5000 (instead of localhost)
   - Clear browser cache (Ctrl+Shift+Delete)
   - Try different browser


❌ Problem: Analysis is slow

Solution:
   - Use smaller images (< 10MB)
   - Close other applications
   - Check available RAM
   - System works best with 4GB+ RAM

                        REST API (Advanced Users)
==============================================================================

While server is running, you can test the API:

🔗 Web-Based API Tester:
   Go to: http://localhost:5000/api/docs
   View all available endpoints


📝 Using cURL (Command Line):

1. Analyze a single image:
   
   curl -X POST http://localhost:5000/api/analyze \
     -F "image=@/path/to/image.jpg"

2. Get system statistics:
   
   curl http://localhost:5000/api/statistics

3. Get feature extractors list:
   
   curl http://localhost:5000/api/extractors


🐍 Using Python:

   import requests
   
   with open('image.jpg', 'rb') as f:
       response = requests.post(
           'http://localhost:5000/api/analyze',
           files={'image': f}
       )
       result = response.json()
       print(result)

==============================================================================
                        IMPORTANT NOTES
==============================================================================

⚠️ First Time Setup:
   - Setup takes 2-3 minutes (downloads dependencies)
   - Do NOT interrupt the setup process
   - Large file downloads may occur (python packages)
   - See "Recent Python packages" in terminal

⚠️ System Requirements:
   - Python 3.8 or higher (automatically needed)
   - 4GB RAM minimum (8GB recommended) 
   - 500MB free disk space
   - Modern web browser (Chrome, Firefox, Safari, Edge)

⚠️ Internet Connection:
   - NOT required to run the app
   - Only needed during setup (to download packages)
   - System runs completely offline after setup

⚠️ Port 5000:
   - Default port for the web server
   - If already in use, change in backend/app.py
   - Or use: run_windows.bat uses 5000 automatically
