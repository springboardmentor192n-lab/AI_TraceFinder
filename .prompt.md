# 🎯 AI TraceFinder - Copilot Prompts & Best Practices

## Context for AI Assistants

You are assisting with **AI TraceFinder**, an advanced image forensics and scanner identification system. The project uses:
- **Backend**: Python/Flask for image analysis and ML inference
- **Frontend**: Vanilla JavaScript for responsive web UI
- **Models**: Keras neural networks and scikit-learn ensemble models
- **Features**: PRNU analysis, FFT, texture descriptors, tampering detection
