      Help & Documentation

      Frequently Asked Questions

      How does scanner identification work?

      AI TraceFinder uses advanced forensic techniques including PRNU (Photo Response Non-Uniformity) analysis, FFT (frequency domain) analysis, and machine learning to identify unique signatures present in images from different scanners/cameras.

      What image formats are supported?

      Supported formats include JPG, JPEG, PNG, TIFF, BMP, and GIF. Images are analyzed at their native resolution, though very large images may be resized for performance.

      How accurate is the analysis?

      Accuracy depends on image quality and the scanner model database. Typical confidence scores range from 0.5 (uncertain) to 0.99 (very confident). Our system has been tested with 90%+ accuracy on known scanner types.

      Can it detect image tampering?

      Yes! TraceFinder analyzes forensic indicators including compression artifacts, unusual patterns, channel mismatches, and other signs of potential image manipulation.

      Is there a file size limit?

      The maximum file size is 50MB. For best performance, we recommend using images under 10MB. Analysis typically takes 0.08-0.5 seconds per image.

      Can I analyze multiple images at once?

      Yes! Use the Batch Upload feature to analyze up to 10 images simultaneously. Results are shown in an organized table format.

      Quick Start Guide

      1. Upload Image: Navigate to Analyze tab and upload or drag-drop an image
      2. Wait for Analysis: The system will extract features and identify the scanner (takes ~0.08-0.5 seconds)
      3. Review Results: Check the identified scanner, confidence score, and forensic indicators
      4. Download Report: Export results as JSON or HTML report for documentation
      5. Track History: All analyses are automatically saved in the History section
